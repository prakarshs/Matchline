Measure the matching.

This page reads the real sequencer's counters, not simulated numbers. In public mode it follows the laboratory's isolated browser session. No trading decisions are made here.

CONNECTING—
01 / COMMANDS ADMITTED—Accepted into the bounded writer queue
02 / COMMANDS COMPLETED—Sequenced outcomes, including business rejections
03 / QUEUED WORK—Waiting / configured capacity
04 / INGRESS REJECTED—Queue full or writer not accepting
05 / PROCESSING p95—Approximate histogram bucket upper bound
06 / ACKNOWLEDGEMENT p99—Admission to confirmed sequenced decision
What this is

Session-scoped JSON metrics from /api/v1/metrics, refreshed every 4 seconds. In public mode counters reset when this temporary session expires.

What this isn't

Not a Prometheus or Grafana dashboard. Spring's /actuator/prometheus exports process-wide metrics and is intentionally not public in demo mode.
